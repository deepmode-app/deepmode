Deepmode

Install the Deepmode Chrome extension

Deepmode runs through the extension. Once it’s installed, you can start blocks from any tab and see your stats on the dashboard.

While we’re in beta, install it in developer mode:
  1. Download the Deepmode extension ZIP.
  2. Unzip it – you should now have a folder called deepmode-extension (or similar).
  3. In Chrome, go to chrome://extensions and turn on Developer mode in the top-right.
  4. Click “Load unpacked” and choose the unzipped Deepmode folder (not the ZIP).

When the Chrome Web Store listing is live, this page will link directly to it. For now, this gets you a working local version so you can test Deepmode end to end.
