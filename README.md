### Chrome extensions

- `extension-dev/`  
  - Uses API_BASE_URL = https://deepmode.onrender.com  
  - Manifest name: "Deepmode AI - DEV"  
  - For local development (Load unpacked in Chrome).

- `extension-prod/`  
  - Uses API_BASE_URL = https://deepmode.app  
  - Manifest name: "Deepmode AI"  
  - This folder is zipped and uploaded to the Chrome Web Store.
