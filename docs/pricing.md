# Deepwork AI – Pricing Tiers (Draft)

## Free
- Up to 100 minutes of deep work per day (4 × 25 min sessions)
- Basic dashboard (today + all time)
- Blocks a limited set of sites (YouTube, Twitter)

## Pro (e.g. £8–10/month)
- Unlimited sessions
- Unlimited minutes
- Full dashboard history (30/90 days)
- Discipline streaks + weekly summary
- Configurable blocked sites list
- Priority “coach” prompts (AI-based in future)

## Future: Teams / Enterprise
- Team dashboard (per-member stats)
- Shared focus sessions
- Admin controls (enforced blocking)
